# bop2flex

Sample size deviations in Bayesian optimal phase II designs.

The Bayesian optimal phase II design (BOP2; Zhou, Lee and Yuan, 2017) and its extension with futility and efficacy stopping (BOP2-FE; Xu, Hashimoto, Yimer and Takeda, 2026) are calibrated for planned interim and final sample sizes. In practice the number of evaluable patients at an analysis often differs from the plan. Because the probability cutoffs are written as functions of the information fraction `n / N`, it is tempting to evaluate them at the actual sample sizes. This naive practice can raise the type I error rate above its nominal level. **bop2flex** computes boundaries at the actual analyses that keep the type I error rate at or below the nominal level for any schedule of analyses, and that coincide with the planned boundaries when the trial follows its plan. All operating characteristics are computed exactly, without simulation, for a single binary endpoint.

## Installation

```r
# install.packages("remotes")
remotes::install_github("gosukehommaEX/bop2flex")
```

## Example

A trial with a null response rate of 0.2 and an alternative of 0.4 plans analyses after 10, 15, 20, 25, 30, 35 and 40 patients. `flex_design()` calibrates the BOP2-FE design by the grid search of Xu et al. (2026), with exact operating characteristics.

```r
library(bop2flex)
design <- flex_design(p0 = 0.2, p1 = 0.4, n = c(10, 15, 20, 25, 30, 35, 40),
                      alpha = 0.1)
design
```

The selected tuning parameters are `lambda = 0.87`, `gamma = 0.94` and `eta = 2.4`. The trial stops for futility when the number of responses is at most 1, 2, 3, 5, 7 and 8 at the interim analyses, and stops for efficacy when it is at least 6, 8, 9, 9, 10 and 11. At the final analysis the null hypothesis is rejected with at least 12 responses. These are the BOP2-FE-1 boundaries of Xu et al. (2026, Table 1). The exact type I error rate is 0.0988 and the power is 0.890. Seven other grid points give the same boundaries, for example `lambda = 0.88`, `gamma = 1` and `eta = 2.3`; they are listed in `design$calibration$equivalent`. They define the same planned design but different probability cutoffs at other sample sizes, so the tuning parameters should be stated together with the boundaries.

Suppose the analyses actually take place after 12, 16, 19, 25, 31, 37 and 39 patients. `flex_update()` is called at each analysis with the sample sizes so far.

```r
flex_update(design, m = c(12, 16, 19))
flex_update(design, m = c(12, 16, 19, 25, 31, 37, 39), final = TRUE)
```

The efficacy boundaries are 7, 8, 9, 9, 11, 12 and 12, and the exact type I error rate of the procedure is 0.085. Evaluating the planned cutoffs at the actual sample sizes gives the efficacy boundaries 7, 8, 8, 9, 10, 11 and 11, with a type I error rate of 0.127.

```r
flex_naive(design, m = c(12, 16, 19, 25, 31, 37, 39), final = TRUE)
```

`flex_compare()` evaluates both approaches over many schedules, for example random deviations around the plan generated by `flex_schedules()`.

```r
schedules <- flex_schedules(design, n_sim = 1000, seed = 1)
res <- flex_compare(design, schedules)
aggregate(cbind(type1, power, en0) ~ method, data = res, FUN = mean)
tapply(res$exceeds_alpha, res$method, mean)
```

A design obtained elsewhere, for example from a trial protocol, can be specified by its tuning parameters or by its boundaries with `flex_plan()`.

```r
design_tab <- flex_plan(p0 = 0.2, n = c(10, 15, 20, 25, 30, 35, 40),
                        alpha = 0.1,
                        futility = c(1, 2, 3, 5, 7, 8),
                        efficacy = c(6, 8, 9, 9, 10, 11, 12), p1 = 0.4)
```

## Method

The planned design, applied under the null response rate, spends its type I error rate over the planned analyses. `flex_spending()` returns these cumulative amounts, and joining them linearly in the information fraction gives the error spending function implied by the design. At each actual analysis, `flex_update()` computes the distribution of the number of responses among trials that are still running, given the boundaries actually applied earlier. The spending boundary is the smallest count for which the cumulative type I error rate does not exceed the spending function at the current information fraction. At the final analysis the error rate not spent earlier is used, up to the nominal level. The efficacy boundary is the larger of the spending boundary and the boundary of the planned efficacy cutoff at the actual sample size. The futility boundary is the planned futility cutoff evaluated at the actual sample size.

The procedure has three properties.

* When the analyses take place as planned, the planned boundaries are recovered.
* For any sequence of analysis sample sizes chosen without regard to the observed responses, the type I error rate is at most the nominal level.
* Efficacy is never claimed with weaker posterior evidence than the planned design requires at the same sample size. At an interim analysis of the BOP2-FE design, the efficacy boundary is never below the smallest count whose posterior probability `Pr(p > p0 | data)` reaches the planned efficacy cutoff `C_E(t)` at the actual information fraction, and at the final analysis never below the smallest count that reaches `lambda`. The BOP2 design does not stop for efficacy at an interim analysis. The boundaries are therefore the naive ones, with an efficacy boundary raised where the naive one would spend more than the spending function allows. Without this floor, a trial with few continuing outcomes under the null could reject with an efficacy boundary of zero.

For a design given only by its boundary table, the cutoffs at unplanned sample sizes are unknown, and the smallest posterior probability at the planned efficacy boundaries replaces both `C_E(t)` and `lambda` in the floor.

For sensitivity analyses, `flex_update()` accepts another spending function through `spending` and omits the floor with `efficacy_floor = FALSE`; the type I error guarantee holds in both cases. With the floor, a spending function that is at least the implied one at every planned interim analysis also recovers the planned boundaries.

Futility stopping is binding by default, as in Zhou et al. (2017) and Xu et al. (2026). With `binding = FALSE` the type I error rate is computed without the futility boundaries, and the guarantee holds whether or not they are followed. Both efficacy cutoffs of Xu et al. (2026) are available, the power function (`method = "power"`, BOP2-FE-1) and the O'Brien-Fleming type function (`method = "OF"`, BOP2-FE-2). The BOP2 design with futility stopping only is obtained with `type = "BOP2"`.

## Functions

| Function | Purpose |
|---|---|
| `flex_design()` | Calibrate a BOP2 or BOP2-FE design by grid search |
| `flex_plan()` | Specify a design by its tuning parameters or boundaries |
| `flex_boundary()` | Boundaries of the probability cutoffs at given sample sizes |
| `flex_oc()` | Exact operating characteristics of boundaries on a schedule |
| `flex_posterior()` | Posterior probability that the response rate exceeds `p0` |
| `flex_spending()` | Error spending implied by a planned design |
| `flex_update()` | Boundaries at the actual analyses by the implied spending function |
| `flex_naive()` | Planned cutoffs evaluated at the actual sample sizes, for comparison |
| `flex_compare()` | Operating characteristics of both approaches over schedules |
| `flex_schedules()` | Random schedules of actual sample sizes around the plan |

## Validation

The tests compare the package with published values and with an independent implementation in Python.

* `flex_design()` reproduces the BOP2 boundaries of Zhou et al. (2017, Table I, Example 1), the BOP2-FE-1 boundaries of Xu et al. (2026, Table 1) and the BOP2-FE-2 boundaries of Xu et al. (2026, Supplementary Table S1).
* The exact operating characteristics agree with the simulated values of Zhou et al. (2017, Table II, scenario 1) and Xu et al. (2026, Table 3, scenario 1) within simulation error.
* The boundaries, spending functions and operating characteristics agree with an independent Python implementation of the same procedures.

Two published values were not used. In Zhou et al. (2017, Table II), the percentage rejecting the null at a response rate of 0.3 (55.2 percent) and the percentage of early termination (46.2 percent) add to more than 100 percent; Xu et al. (2026, Table 3) report 52.8 percent for the same boundaries, and the exact value is 52.8 percent. The BOP2-FE-2 boundaries printed in Table 2 of Xu et al. (2026) differ from those in their Supplementary Table S1; the exact grid search selects the latter.
